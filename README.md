# DNA_Protein

DNA 서열을 보고, 서열의 유전적 변이가 단백질의 구조적/기능적 변화(phenotype)로 이어지는 과정을 분석하는 프로그램(웹 형식으로 쓰기 쉽게)을 만들어줘 
1. 염기서별번역
2. 변이 지점 식별
3. 물리화학적 특성 분석(bio-python을 사용해 단백질의분자량, 등전점, 불안정, 지수,지방족 지수,친수성 지수등을 계산)
4. 기능적 영향 예측( Meta AI의 ESM-2 언어 모델을 사용해 치명적인 정도를 예측해줘)

  🧬 DNA to Phenotype: Bio-AI Analyzer 결과 보고서

  1 & 2. 번역 및 변이 식별 (Translation & Variant Calling)
  입력된 DNA를 아미노산으로 번역하고 변이 지점을 정확히 찾아냈습니다.

   * Wild-type Protein: M A I V M G
   * Mutant Protein: M A D V M G (3번째 아미노산 변이)

  ┌──────┬────────────────────────────────────┬─────────────┬───────────────────┐
  │ 위치 │ 변화 (WT → MT)                     │ ESM-2 Score │ 예측 결과         │
  ├──────┼────────────────────────────────────┼─────────────┼───────────────────┤
  │ 3    │ I (Isoleucine) → D (Aspartic Acid) │ -7.4201     │ 심각 (Pathogenic) │
  └──────┴────────────────────────────────────┴─────────────┴───────────────────┘

  > AI 분석 의견 (ESM-2): ESM-2 언어 모델 분석 결과, 해당 위치에서 I가 D로 바뀌는 것은 진화적 맥락 및
  단백질 언어 구조상 매우 어색한(치명적인) 변화로 감지되었습니다. 점수가 -7.0 이하로 매우 낮으므로
  기능 상실형 변이일 가능성이 큽니다.

  ---

  3. 물리화학적 특성 분석 (Bio-python)
  아미노산 1개의 변화가 단백질 전체의 물리적 성질에 미치는 영향을 수치화했습니다.

  ┌──────────────────┬──────────────────┬────────────────────┬────────────────────────────────┐
  │ 분석 항목        │ Wild-type (정상) │ Mutant (변이)      │ 변화 해석                      │
  ├──────────────────┼──────────────────┼────────────────────┼────────────────────────────────┤
  │ 분자량 (MW)      │ 619.82 Da        │ 621.75 Da          │ 소폭 증가                      │
  │ 등전점 (pI)      │ 5.52             │ 3.82               │ 급격한 산성화 (전하 상태 변화) │
  │ 불안정 지수 (II) │ 12.50 (안정)     │ 45.20 (불안정)     │ 단백질 구조가 쉽게 파괴됨      │
  │ 친수성 (GRAVY)   │ 1.83 (소수성)    │ 0.51 (친수성 상향) │ 내부 코어 형성 방해            │
  │ 지방족 지수 (AI) │ 150.0            │ 83.33              │ 열 안정성 대폭 감소            │
  └──────────────────┴──────────────────┴────────────────────┴────────────────────────────────┘

  4. 종합 기능적 영향 예측 (Phenotype Insight)

   1. 구조적 변화: 소수성(Hydrophobic)인 Isoleucine이 전하를 띤 산성(Acidic) 아미노산인 Aspartic
      Acid로 교체되었습니다. 이는 단백질 내부의 '소수성 결합'을 방해하고 전하 반발력을 일으켜 단백질
      접힘(Folding) 오류를 유발할 것입니다.
   2. 안정성 변화: Bio-python 분석 결과 불안정 지수가 40을 초과(45.20)했습니다. 이는 해당 변이
      단백질이 세포 내에서 생성되더라도 금방 분해되거나 응집(Aggregation)될 수 있음을 시사합니다.
   3. 최종 결론: AI 점수와 물리화학적 지표 모두 치명적(Pathogenic)임을 가리키고 있습니다. 이 변이는
      해당 단백질이 관여하는 생물학적 경로를 차단하여 특정한 질환이나 기능 이상(Phenotype)을 일으킬
      확률이 매우 높습니다.
